How do I add a Hindi voice?

This app uses voices provided by your browser and device; it cannot install a voice itself.

  • Windows: Open Settings → Time & language → Speech, then look for Manage voices or Add voices. Add a Hindi voice if your Windows edition offers one.
  • Android: Open Settings → Accessibility or General management → Text-to-speech output. In your preferred engine, install a Hindi voice if available.
  • iPhone/iPad: Open Settings → Accessibility → Spoken Content → Voices, then download a Hindi voice if listed.
  • Mac: Open System Settings → Accessibility → Spoken Content → System Voice → Manage Voices, then add Hindi if available.

After installing, restart the browser or press Refresh installed voices. Hindi appears here only when the browser reports a voice tagged hi-IN.
